Before you send the report

Editorial checklist / Revision 2

1. Read the title and opening paragraph together. They should describe the same question.

2. Check every date, amount, name and page reference against the source.

3. Replace vague phrases with specific facts where the evidence supports them.

4. Make sure each table has a title, units and a clear explanation of missing values.

5. Confirm that the final file opens correctly and includes the intended attachments.

Save a dated copy before sending. Keep the working notes with the original source material.
